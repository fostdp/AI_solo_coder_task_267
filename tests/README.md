## 🔍 核心算法说明

### 音频频率计算
```javascript
// 十二平均律公式：f = f0 * 2^(n/12)
function calculateFrequency(baseFreq, semitone) {
    return baseFreq * Math.pow(2, semitone / 12);
}
```
- 基准音：中央C (261.63Hz)
- 半音：每升高1个半音频率乘以2的1/12次方

### 计分系统
```javascript
// 基础分10分 + 连击加成 (连击数×2)
// 注意：实际代码中先增加streak再计算分数
function calculateScore(isCorrect, currentStreak) {
    if (!isCorrect) return 0;
    const newStreak = currentStreak + 1;  // 先增加
    return 10 + newStreak * 2;            // 再计算
}
```

| 连击状态 | 说明 | 得分 |
|---------|------|------|
| currentStreak = 0 | 第一题 | 12分 |
| currentStreak = 4 | 第5题（5连击） | 20分 |
| currentStreak = 9 | 第10题（10连击） | 30分 |
